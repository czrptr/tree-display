# `tree-display-derive`

[![Crates.io](https://img.shields.io/crates/v/tree-display-derive.svg)](https://crates.io/crates/tree-display-derive)
[![Docs.rs](https://docs.rs/tree-display-derive/badge.svg)](https://docs.rs/tree-display-derive)

Procedural macro implementation for `tree-display`. This crate provides the `#[derive(TreeDisplay)]` macro.

> **Note:** This crate is an implementation detail of `tree-display`. You should not use it directly. Use the `tree-display` crate instead.
